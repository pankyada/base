## recon
### L1
Required artifact sections: `Files touched`, `Prior knowledge`, `Open questions`.
Exit criteria: source material and style constraints recorded.
## plan
### L1
Required artifact sections: `Plan`, `Audience`, `Risks`.
Exit criteria: outline and argument spine fixed.
## design
### L1
Required artifact sections: `Design`, `Voice`, `Structure`.
Exit criteria: section structure fixed.
## build
### L1
Required artifact sections: `Result`.
Exit criteria: draft produced.
## verify
### L1
Required artifact sections: `Verification`, `Fact check`.
Exit criteria: facts and consistency checked.
## review
### L1
Required artifact sections: `Review`, `Generalization`.
Exit criteria: edit pass and wider applicability reviewed.
