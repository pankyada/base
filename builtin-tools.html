Built-in Tools ​

The harness ships 18 built-in tools. ACL for each is set in tools.builtin of the profile YAML (or inherited from mode:).

ACL values ​

ValueMeaning
allowTool executes without prompting
promptUser must approve each call at runtime
denyTool call rejected immediately

File tools ​

Read ​

Read a file. Returns content with line numbers (cat -n format).

ACL default: allow

ParamTypeRequiredDescription
file_pathstringyesAbsolute path to file
offsetnumbernoStart line, 1-indexed (default 1)
limitnumbernoMax lines to read (default 2000)
json
{ "file_path": "/etc/hosts", "offset": 1, "limit": 50 }

Write ​

Write content to a file, creating parent directories as needed.

ACL default: allow

ParamTypeRequiredDescription
file_pathstringyesAbsolute path to file
contentstringyesContent to write

Edit ​

Replace an exact string in a file.

ACL default: allow

ParamTypeRequiredDescription
file_pathstringyesAbsolute path to file
old_stringstringyesExact text to find (must be unique unless replace_all)
new_stringstringyesReplacement text
replace_allbooleannoReplace every occurrence (default false)

Grep ​

Search for a regex pattern in files.

ACL default: allow

ParamTypeRequiredDescription
patternstringyesSearch pattern
pathstringyesFile or directory to search
flagsstringnogrep flags (default: -rn)

Glob ​

Find files matching a glob pattern.

ACL default: allow

ParamTypeRequiredDescription
patternstringyesGlob pattern (e.g. src/**/*.ts)
cwdstringnoWorking directory (default: process.cwd())

Shell tool ​

Bash ​

Execute a bash command. stdout + stderr combined.

ACL default: prompt

ParamTypeRequiredDescription
commandstringyesShell command
timeoutnumbernoTimeout in ms (max 120000, default 120000)

Skill tool ​

Skill ​

Load and return a skill by name. Returns the full SKILL.md content.

ACL default: allow

ParamTypeRequiredDescription
namestringyesSkill name as listed in the skill index

ContextRestore ​

Restore the full result of an earlier tool call that was elided from the model's context projection. The result remains in the session ledger; this tool retrieves it by the stored tool_call_id.

ACL default: allow

ParamTypeRequiredDescription
idstringyesEarlier tool-call id
offsetnumbernoCharacter offset, default 0
limitnumbernoMaximum characters to restore

When limit truncates output, the result ends with a remaining-character marker. Old sessions without stored tool-call ids return a clear unavailable message.

Memory tools ​

All memory tools operate on one of three scopes:

ScopeStorageLifetime
sessionIn-memory on SessionUntil session ends
profile<artifact_dir>/memory/*.mdPersistent, shared across all users
user~/.harness/memory/<profile>/<user>/*.mdPersistent, private to one user

MemoryRead ​

ACL default: allow

ParamTypeRequired
scopesession | profile | useryes
keystringyes

MemoryWrite ​

Default scope is user (private). Use profile to share across all users.

ACL default: allow

ParamTypeRequiredDescription
scopesession | profile | usernoDefault: user
keystringyesShort slug (e.g. project-context)
contentstringyesMarkdown content
linksarraynoGraph links: [{ target: "other-key", relation: "depends_on" }]

MemoryList ​

ACL default: allow

ParamTypeRequired
scopesession | profile | useryes

MemoryDelete ​

ACL default: allow

ParamTypeRequired
scopesession | profile | useryes
keystringyes

MemoryLinked ​

Graph traversal — finds entries that the key links to (forward) and entries that link to the key (reverse).

ACL default: prompt

ParamTypeRequiredDescription
scopesession | profile | useryes
keystringyesAnchor memory key
relationstringnoFilter by relation type

Stats tool ​

Stats ​

Show usage stats from telemetry: top tools, skills, MCP calls, cost breakdown.

ACL default: allow

ParamTypeRequiredDescription
since_daysnumbernoShow last N days (default 7)
profilestringnoFilter by profile (default: current)

Agent tools ​

Delegate ​

Delegate a task to a sub-agent running under a different profile. Returns the final reply and tool summary.

ACL default: prompt

ParamTypeRequiredDescription
profilestringyesTarget profile name (e.g. researcher)
taskstringyesTask description for the sub-agent

User interaction tools ​

AskUser ​

Pause the agent loop and ask the user a question. Resumes when the user responds.

ACL default: allow

ParamTypeRequiredDescription
promptstringyesQuestion to ask
kindtext | select | multi_selectyesInput type
optionsstring[]noRequired for select and multi_select

TodoWrite ​

Replace the current session todo list. Always pass the complete list — this overwrites everything.

ACL default: allow

ParamTypeRequired
items{ id, content, status, priority }[]yes

status: pending | in_progress | completed
priority: high | medium | low

TodoRead ​

Return the current todo list as JSON.

ACL default: allow

No parameters.

Code execution tool ​

ExecuteCode ​

Execute code in a sandbox. Requires an executor: block in the profile.

ACL default: allow

ParamTypeRequiredDescription
codestringyesSource code
languagestringyespython, javascript, bash, ruby, etc.
dataobjectnoPassed to executor as /work/data.json
timeout_msnumbernoOverride profile executor.timeout_ms

Returns: exit code, stdout, stderr, duration, and any files written to /out/.

yaml
# Required in profile to enable ExecuteCode:
executor:
  default: docker
  docker_image: python:3.12-slim
  timeout_ms: 30000
