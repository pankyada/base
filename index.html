HarnessA WebSocket-based agent harness

Wire LLMs to tools, skills, memory, and MCP servers — all from a profile YAML.

Get Started
GitHub
📋

Profile-driven

Everything — model, tools, memory, hooks — defined in a single YAML file. No code changes to add a new agent type.

🔌

MCP-native

Connect any MCP server (stdio, HTTP, SSE, WebSocket) with per-tool ACL and automatic schema discovery.

🤝

Multi-agent

Agents compose via the agents block. Orchestrate workers with typed I/O contracts and parallel fan-out.

🔒

Instance modes

developer / analyst / assistant / production — each sets default tool ACLs and validates the deployment trust model.

⚡

Triggered + durable

Cron and webhook triggers wake agents on a schedule or external event. Runs checkpoint to disk and resume after crashes.

🧠

Self-improving

Post-session reflection writes key learnings to memory. Skill mining extracts reusable patterns every N sessions.
