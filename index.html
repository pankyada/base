Use Cases
GitHub
📋

Profile-driven

Everything — model, tools, memory, hooks, channels — defined in a single YAML file. No code changes to add a new agent type.

🛡️

Conditional ACL

'Allow this tool when the arguments look like this, ask otherwise.' A closed, data-only predicate set — no code eval, deny always wins.

🚧

Provenance gate

Content the agent reads can never silently authorize an action. A monotonic taint flag escalates outbound/destructive tools regardless of ACL — yolo mode can't bypass it.

💬

Durable deferred asks

AskUser({ defer:true }) parks a question to disk and resumes hours or days later, across a full server restart — not an in-memory promise that dies with the connection.

⏱️

Watch & poll triggers

Filesystem watch and cursor-based poll triggers, with a free no-change path — zero model calls when nothing changed.

💰

Autonomy budgets

Hard cost / tool-count / wall-time ceilings checked before every model and tool call, with a complete undo-able audit trail.

🕰️

Temporal memory

Facts carry validity intervals and recurrence instead of being implicitly eternal — Recall answers "what was true at time T," fully backward compatible.

📡

Pluggable channels

A named, bidirectional transport to reach a human — approvals, notifications, and deferred questions, with no vendor in core.

🔌

MCP-native

Connect any MCP server (stdio, HTTP, SSE, WebSocket) with per-tool ACL and automatic schema discovery.

🤝

Multi-agent

Agents compose via the agents block. Orchestrate workers with typed I/O contracts, parallel fan-out, and a shared autonomy budget.

🎙️

Streaming voice

Binary audio transport, streaming STT/TTS as pluggable interfaces, sentence-chunked synthesis, and barge-in that cancels the in-flight model turn.

📐

Context projection

Durable session ledgers project into a budgeted context with restorable tool output, explicit pins, digest promotion, and calibrated token estimates.
