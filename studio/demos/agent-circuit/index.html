THE DESIGN INTENT

Follow the work.
Understand the wait.

Agent Circuit puts delegation, evidence transfer, and human decisions in the same field of view. Positions stay stable while state changes.

One truth, two views
The circuit and activity lanes use the same time-indexed fixture state. Scrubbing does not create new execution.
Motion carries meaning
Moving dashes indicate active delegation or an explicit handoff. Paused replay and reduced motion stop all animation.
Decisions stay explicit
Exact tool arguments remain visible. This demo simulates approval, denial, failure recovery, and delivery.
Runtime boundary
This is a standalone visual prototype. Live attach, durable replay, and correlated acknowledgements require production contracts.
