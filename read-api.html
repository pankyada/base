Read API ​

The server exposes accumulated harness state on the same port as the WebSocket transport. Browser requests must match HARNESS_ALLOWED_ORIGINS; bearer auth continues to apply when HARNESS_API_KEY is configured.

All routes accept user for namespace selection. They are read-only except POST /datasets, which accepts one multipart file and optional name.

RoutePurpose
GET /metricsTool, model, stage, and daily telemetry aggregates.
GET /usageUsage ledger plus monthly series.
GET /auditPaginated audit entries and filters.
GET /memoryScoped memory list/query with temporal fields.
GET /triggersConfigured cron, watch, and poll snapshots.
GET /sessions/:id/messagesPaged transcript projection.
GET /stats/routingRouting aggregate used by the CLI.
GET /datasetsUploaded dataset metadata.
GET /datasets/:id/schemaInferred CSV/JSON schema.
GET /datasets/:id/preview?rows=50Bounded preview rows.
POST /datasetsMultipart dataset upload.

/audit and /memory return Cache-Control: no-store. The aggregate endpoints return a short cache lifetime and ETag. Missing source files return empty data, not errors, so new installations render cleanly.
